# The transcription model itself lives in requirements-model.txt: on Linux +
# Python 3.11 `pip install basic-pitch` would pull TensorFlow (~600 MB) even
# though this project runs the ONNX graph. Installing it with --no-deps and
# listing its non-TF closure here keeps the image lean and deterministic.
