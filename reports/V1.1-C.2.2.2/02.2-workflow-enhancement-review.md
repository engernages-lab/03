## 3. 新增内容逐项说明

### 3.1 新步骤 19：`SPA and static assets over HTTP`

插入位置：`Access gate enforced` 之后、`Container runtime info` 之前（容器已 ready）。

| 断言 | 做法 |
| --- | --- |
| 首页 200 | `curl -w '%{http_code}'` + `test` |
| Content-Type | 响应头 grep `content-type: *text/html` |
| 响应非空 | `test -s` |
| 是 HTML 文档 | grep `-qi '<html'` |
| 不是门禁错误页 | 断言响应体**不含** `ACCESS_GATE_REQUIRED` |
| 匿名首页被拒 | 无凭据 `GET /` → 必须 **401** |
| 基路径 | HTML 必含 `/assets/`，**不得**含 `/03/` |
| 资源名来源 | `grep -oE '/assets/[^"]+\.(js\|css)'` 从**真实 HTML 提取**，`sort -u` 去重 |
| JS/CSS 均存在 | 各至少 1 个，否则非零退出 |
| 每个资源 200 + 非空 | 逐个 `curl`，`test -s` |
| 每个资源 Content-Type | JS 含 `javascript`、CSS 含 `css`（用 `case` 分流） |
| 不被错误页顶替 | 资源体前 64 字节不得是 `<!doctype html` |
| 每个资源匿名 401 | 无凭据请求同一路径 |
| 清理 | `mktemp -d` + `trap ... EXIT` |

### 3.2 新步骤 23：`Upload size limit returns 413`

插入位置：`Reject an unsupported upload`（415）之后、停容器之前。

| 断言 | 做法 |
| --- | --- |
| 读取真实限制 | `docker exec <container> printenv POCKETSCORE_MAX_UPLOAD_MB`（**不硬编码 50**） |
| 构造超限文件 | `printf 'RIFF'` + `head -c $((size*1024*1024)) /dev/zero`，真实字节非稀疏；`size = limit + limit/10 + 1` |
| 为什么 +10% | 服务端早检查阈值是 `limit*1.05`，50MB→56MB 必然触发 |
| 超限 → 413 | 断言 HTTP 状态严格等于 `413` |
| 错误信封 | 响应体必含 `PAYLOAD_TOO_LARGE` |
| 边界：限额内仍可用 | 上传 `tests/fixtures/melody.wav`，断言 **201** |
| 临时文件 | `mktemp -d` + `trap` 清理，不落仓库、不落持久化目录 |
| curl 退出码 | 服务端提前响应会断连，用 `|| echo "curl exit=$?"` 记录后**以 HTTP 状态为断言**（不掩盖失败） |
